# 文献总结结构与写法模板

四个模块，顺序固定。草案阶段照此输出 Markdown；导出 Word 时层级不变。

```
一、文献名片
二、主要内容概括
三、创新点（两条）
四、可借鉴到本课题（两到三条）
```

多篇合并时，每篇在四节之外不再增补任何小节；不写证据链表、不写局限与不足、不写与本课题已有工作的对照、不写本周可动手、末尾不附参考文献条目。

---

## 总体文风

- 学术书面语，第三人称。称"作者"或"该文"。
- 一句话只说一件事，长句拆开。不堆修饰词。
- 不用"总的来说""综上所述""希望对你有帮助"收尾。
- 出现的每个数字都要能指回图表或正文位置。

---

## 一、文献名片

三线表，不写裸段落。六行固定项目，缺一不可。

| 项目 | 内容 |
|---|---|
| 题目 | 原文英文全题 |
| 作者 | 第一作者 et al.（通讯作者标 \*） |
| 期刊 | 期刊名 年, 卷(期), 起止页 |
| DOI | 10.xxxx/xxxxx |
| 文献类型 | 研究论文 / 综述 / 通讯 / 方法学 |
| 影响因子 / 分区 | 分开写，各带口径年份与来源 |

**影响因子的写法**：`影响因子 14.4（2024 JCR，Clarivate）；中科院分区 化学 1 区 Top（2025 年升级版）`。两个口径不许揉成一句，也不许只写一个数字了事。逐年变动，必须注明哪一年。

**查证纪律**：文献页面没有就联网查，查完注明来源；检索不到时写"待核实（已查 JCR 与期刊官网，未见公开数据）"，绝不凭记忆填。

## 二、主要内容概括

150～250 字，一段话，四句话结构：

```
1. 体系与做法：作者用<什么策略>构建了<什么体系>，以<什么方法>为主。
2. 关键结果一：<最重要的定量结论>。
3. 关键结果二：<次重要的定量结论>。
4. 落点：结论主要支持<什么判断>，或指向<什么应用场景>。
```

**要求**：读完这一段，读者应能判断"这篇和我有没有关系"。数字最多用三处，多了就成了抄摘要。

**反例（夹评价、堆术语）**：
> 该文创新性突出，系统研究了 IAP 类光开关的性能，结果令人满意，为相关领域提供了重要参考。

**反例（等于抄摘要）**：
> 作者报道了一类新型偶氮光开关，具有高水溶性、可见光响应、高量子产率和可调半衰期，在光药理学与材料领域有广阔前景。

**正例**：
> 作者以杂芳环直接构建偶氮骨架的策略，合成了以 2-咪唑偶氮-4-吡唑（4pz）为代表的一类光开关，主用 UV-Vis 与变温动力学表征。水中饱和浓度达 115.0 mM，比已报道的代表性水溶性可见光偶氮高一个数量级以上；400 nm 与 550 nm 下双向异构分别为 83% 与 >99%，水中量子产率 0.41 与 0.67。结论支持"极性杂芳环骨架可同时提供水溶性与可见光响应"，应用侧落在离子通道光调控与光响应水凝胶的图案化写入。

## 三、创新点（固定两条）

两条，不多不少。每条三段式，缺一段即不合格：

```
创新点N：<一句话命名>
相对于：<对标的已有工作或常规做法>
新在　：<具体不同点，属方法、机理、材料还是表征层面>
证据　：<图X/表Y 支持；是直接证据还是仅相关，对照是否完整>
```

**"证据"一行的分量最重**。判断力全在这里：要写清证据强度，如"属间接证据，缺原位表征"、"对照完整，结论较硬"、"仅单一手段支撑"。这是全篇唯一允许出现评价的地方，写软了整份总结就没有判断。

**判断标准**：把"相对于"那行删掉，句子若仍通顺成立，说明只写了作者做了什么，没写新在哪。

**反例**：
> 创新点1：作者采用计算辅助设计，合成了一系列高水溶性偶氮光开关。

**正例**：
> 创新点1：把水溶性编码进偶氮骨架本身，而非外挂增溶基团
> 相对于：常见做法是引入磺酸、季铵或低聚乙二醇侧链，或做成离子型偶氮
> 新在　：以咪唑与吡唑直接构成偶氮骨架，靠杂芳环偶极与 sp²-N 氢键同时提高极性与溶剂化，无需侧链
> 证据　：Fig. 3c 与 Table S3 给出 115.0 mM，高出已有体系一个量级以上；单晶氢键网络与 ESP 计算互证，属较硬证据。但对照口径为"溶解度或最高工作浓度"混用，严格比较时需留意

**命名分型**（选一类，便于归类）：方法/工艺创新、机理认识创新、材料结构创新、表征与评价方法创新。

## 四、可借鉴到本课题（两到三条）

**这一模块的成败在一行：做法。** 概括和创新点写得再好，这一行虚了整份总结就白写。

写之前先读 `references/project_profile.md`。本课题的基准体系是 Azo-PTA（绿光光热液化、冷却固化），所有借鉴点都要落在这个基准与现实条件之间。

### 每条七行，缺一不合格

```
可借鉴点N：<一句话>
类型　：方法 / 机理判据（二选一）
用在　：<本课题哪个样品体系 / 哪个实验环节>
解决　：<当前具体困难，指到现象，不写“提高性能”>
做法　：<投料、条件、观察指标、时间点；写到别人能照着做>
增量　：<基准已做到 X；本文给到 Y；我因此能 Z>
性质　：可直接照搬 / 需改造 / 仅作思路参考
```

### 两类分别怎么判断能不能借

1. **方法**（表征、测法、数据处理）：问三件事，能否在本体无溶剂样品上做、所需设备手上有无、读数是否与基准可比。任一条不行就降为“需改造”，并在“做法”里写替代方案。
2. **机理判据**：本课题最该借的一类。任何“某效应而非另一效应”的主张，必须连同它的排除性判据一起借。基准把“光热而非光化学”钉死靠四件套：固体 UV-vis、变温 UV-vis、¹H NMR、POM，再配流变 G′/G″ 交叉温度与 DSC 的 Tm 定温度。换了发色团之后这套要重走一遍，只借结论不借判据，等于把漏洞一起继承。

### 两条硬规矩

- **做法**必须至少含一个可执行动作与一个可观察指标。只写“可参考其思路”即不合格。
- **增量**写不出来就删掉这条。基准已经做到的事，不叫可借鉴。

### 反例

> 可借鉴点1：可借鉴其表征手段与实验设计思路。（等于没说，没有动作也没有指标）

### 正例

> 可借鉴点1：给“光热而非光化学”补一套排除性判据
> 类型　：机理判据
> 用在　：对硝基偶氮-TA 体系的相变机理定性，重点排除“光致异构降低熔点”这条替代解释
> 解决　：现在只有目视液化与升温曲线，说不清是光热还是异构，被问到时只能答“应该是热”
> 做法　：四件套并做。固体 UV-vis 看目标波长能否把 cis 拉回 trans；变温 UV-vis 看恒温下是否发生异构；¹H NMR 看照射后有无 cis 特征峰；POM 看升降温中各项同性与各向异性的切换。再配流变 G′/G″ 交叉温度与 DSC 的 Tm，把温度与相变一一对上。样品为无溶剂本体且不透明，UV-vis 改用固体模式与薄膜样；¹H NMR 需可溶或可溶胀条件，做不到就以固体 UV-vis 加 POM 为主并说明证据缺口
> 增量　：基准已在 Azo-PTA 上跑通这套论证；本文给出可直接迁移的判据组合与判读标准，我因此能在新发色团上重建同等强度的证据链，而不是停在口头结论
> 性质　：可直接照搬（判据组合），部分需改造（样品形态）

## 一周多篇的处理

- 一级标题 `文献一：<中文短标题>`，其下四个模块降为二级标题，编号保留一至四。
- 全部文献之后附一张极简清单（一级标题 `本周文献清单`）：列"文献 | 核心体系 | 可否借鉴 | 优先级"四列，最后一句点明本周先看哪篇。清单只做索引，不替代各篇的四模块。

## 学术化改写对照

| 口语/草稿 | 总结里应写成 |
|---|---|
| 作者搞了个新催化剂 | 作者构建了 X 型催化剂 |
| 效果好很多 | 转化率由 A% 提升至 B%（Fig. 2） |
| 说明了这个机理 | 该结果支持……的解释，但不足以排除…… |
| 用了好多表征 | 以 XRD、XPS 与 TEM 分别表征…… |
| 作者没做这个 | 原文未涉及…… |
| 我觉得可以试试 | 可迁移至本体系，需先验证…… |
| 这个方法很有启发 | 把该方法用于<具体环节>，改<某个参数>，观察<某个指标> |
| 可用于某某领域 | 在使用条件（温度/载荷/循环）为 X 时可用，本体系在 Y 这一条上尚不满足 |
